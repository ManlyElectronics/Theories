# Finance–Reality Algebra (FRA)

An algebraic framework representing economic elements as paired **real** (physical) and **financial** components:

> **E = R + V·i**

Where:
- **R** = tangible assets/flows (real axis)
- **V** = financial valuation (imaginary axis)
- **i** marks the valuation axis

Core operations:
- Addition: (R1+V1i) + (R2+V2i) = (R1+R2) + (V1+V2)i
- Scalar: α(R+Vi) = (αR) + (αV)i
- Multiplication: (R1+V1i)(R2+V2i) = (R1R2 − V1V2) + (R1V2 + R2V1)i
- Rotation (revaluation): E' = E·e^{iθ}
